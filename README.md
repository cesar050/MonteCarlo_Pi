# Simulación Monte Carlo - Estimación de π

Implementación de simulación Monte Carlo para estimar el valor de π mediante el método de puntos aleatorios.

## Requisitos

- Node.js >= 16.0.0
- npm >= 8.0.0

## Instalación
```bash
git clone https://github.com/cesar050/MonteCarlo_Pi.git
cd MonteCarlo_Pi
npm install
```

## Ejecución
```bash
npm run dev
```

Abrir en el navegador: http://localhost:5173
